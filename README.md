💳 ATM Banking Simulation

C# Console Application — Basic Banking Operations

This project simulates core ATM banking functions using C#. It includes essential operations such as user authentication, balance inquiry, deposits, and withdrawals. Originally developed during my university years, it helped me practice key concepts like object-oriented programming, control flow, error handling, menu structures, and real-world scenario modeling.

🎯 Learning Outcomes

Through this project I gained hands-on experience with:
Basic algorithm development in C#
Managing menu-driven console applications
Using parameters and structuring methods
Applying conditions, loops, and input validation
Fundamental object-oriented programming principles
